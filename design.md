# Diseño de Metacognición Aplicada

## Filosofía de Diseño

### Paleta de Colores
- **Principal**: #2C3E50 (Azul oscuro profesional)
- **Secundario**: #3498DB (Azul vibrante para acentos)
- **Éxito**: #27AE60 (Verde para progreso y logros)
- **Advertencia**: #F39C12 (Naranja para atención)
- **Neutros**: #ECF0F1, #BDC3C7, #95A5A6 (Grises suaves)
- **Fondo**: #FAFAFA (Blanco suave)

### Tipografía
- **Display**: "Playfair Display" - Serif elegante para títulos
- **Body**: "Inter" - Sans-serif moderna y legible
- **UI**: "Inter" - Consistencia en la interfaz

### Estilo Visual
- **Minimalismo funcional**: Interfaces limpias sin distracciones
- **Profundidad sutil**: Sombras suaves para jerarquía visual
- **Bordes redondeados**: 8px-16px para sensación amigable
- **Espaciado generoso**: Respiración visual entre elementos
- **Iconografía consistente**: Estilo outline con 2px de grosor

## Efectos Visuales

### Animaciones
- **Transiciones suaves**: 300ms ease-in-out
- **Micro-interacciones**: Hover states con escala suave (1.02x)
- **Progreso visual**: Barras animadas y contadores
- **Aparecer gradual**: Fade-in con desplazamiento suave

### Efectos de Fondo
- **Gradiente sutil**: Azul suave degradado en header
- **Patrones geométricos**: Elementos decorativos abstractos
- **Ilustraciones**: Estilo flat design con colores de la marca

### Componentes Clave
1. **Dashboard Cards**: Con sombras suaves y bordes redondeados
2. **Barras de progreso**: Animadas con colores de éxito
3. **Badges y logros**: Diseños circulares con iconos
4. **Formularios**: Inputs modernos con focus states
5. **Botones**: Primarios, secundarios y ghost con estados claros

### Responsive Design
- **Mobile-first**: Diseño adaptable desde 320px
- **Breakpoints**: 768px (tablet), 1024px (desktop), 1440px (large)
- **Tipografía fluida**: Escalado proporcional en todos los tamaños
- **Touch-friendly**: Botones mínimo 44px en móvil
